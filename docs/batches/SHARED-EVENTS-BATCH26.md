## 关卡与奖励核对

核对 `aof3-werewolf-dlc` 归档的 `werewolfdlc.xml`：

- `01` 入口要求非教程、此前未访问，且当前为矮人或森林战役；离开入口后记录访问状态。
- `02` 暂存原队伍并创建冈瑟，进入 `03` 的追猎战斗。`03` 获胜进入 `04`，后者暂存狼人队伍、恢复原队伍并解锁 `05`，返回世界地图。
- `05` 恢复狼人队伍，进入战前商店 `05a`，随后到 `06`。商店根据战役分别调用矮人或森林战前对白。
- `06` 第一项任务要求战斗结束且回合数 `LESS_EQUAL_8`，奖励三个 `LifePotionItem`，译为“治疗药液×3：在第八回合结束前赢得战斗”。第二项要求战斗结束且己方阵亡数为零，奖励300金币。未更改条件、奖励或游戏脚本。
- `07` 战后对话结束后再次暂存并移除狼人队伍，解锁 `08` 并返回地图。因此提示明确冈瑟和狼人只参加这段冒险中的战斗，不把阶段性援助译成永久入队。
- `03` 与 `06` 的失败均进入 `LevelWerewolfDefeat`，复用已译的 `SXX_Defeat_difficulty`，随后结束游戏。失败文本一并译入，未套用主战役的通用失败页。

`WXX_Welcome`、`W02_Dwarves_battle_intro`、`W02_Forest_battle_intro` 来自独立扩展对话资源；已核对引用及战役条件，本批未修改，也未计入完成量。未改其他译者负责的战役文件，不宣称整个扩展或所有战场动态文本已汉化。
