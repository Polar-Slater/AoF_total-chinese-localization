# 战争机器第1批：关卡正文与独立对白

## 来源与范围

关卡采用 `aof5-ratmen/ratmencampaign-en.properties` 的全部323条 `LevelMachineWar*` 文本，涵盖20个有文本的关卡，逐字段与扩展XML核对。保留 `CAMPAIGN=ratmencampaign`，作为扩展单列，不计入主战役完成数；后续主战役工作须避免重复生成这些键。

旧扩展关卡文件有311条内容，当前增加12条战斗任务标签，其余已有英文键值未变。XML另有四条战斗内部摘要和一个隐藏控制关卡标签，未导出到当前英文properties，逐项声明排除，不计入正文分母。当前基线由 `setup_local.py` 提取至忽略的 `source/aof5-machinewar-dlc/current/`，原始参考保留。

六组独立对白为委托介绍24条、金属／煤炭6条、龙骨8条、工具8条、祝贺2条、欢迎4条。全部XML与六处关卡调用已核对，没有未找到关联的本批对白组。BrinWorkshop01内嵌对白第7项是纯图片，原序号保留，不编造台词。

## 译文与术语

沿用因杜尔夫、莱克莎、索罗顿和暗影沼泽；Brin暂译布林，Brin Brass-mane译布林·铜鬃。工具包上的BB保留姓名首字母。矮人的豪爽、吹嘘、饮酒与胡子笑话保留，不刻意增添方言；莱克莎反复说的“I TOLD YOU SO!”统一为“我早就说过了！”。布林忘记口令的原句指代含混，译文使用“不就是忘了那些守卫机器的口令嘛”，不另加未有的解释。

发条巨龙、纯铁、远古煤炭、龙之颅骨及奖励物品沿用正文术语；地点标签附原英文。角色标签Ghost Dragon沿用幽灵龙，任务中的Dracolich沿用龙巫妖，不擅自将两种原文显示名合并。原英文Elixir of Switness按物品ID对应既有迅捷灵药。

## 分支、材料与奖励

- Level05的三项询问分别设置原任务状态并播放对应对白，再以 `goto *` 返回当前菜单。三项状态均达到2，才显示返回地图的选项，解锁工具、煤炭、纯铁和龙骨四处任务。四个按钮、说明、条件及完整命令已查阅；检查器支持经明确审核的当前关卡跳转。
- 工具关卡关于侧门、后门与正门的争论是固定对白，并非三个玩家选项；不新增入口分支。原守卫战、工具包叙述及工坊商店均保留。
- 三条材料路线胜利分别给4份纯铁、2份远古煤炭、1份龙之颅骨。每次胜利后，三类物品各大于0才锁定旧工坊入口、解锁交付关卡。该条件没有要求先完成工具路线，单列为REP-005待调查，不自行补游戏条件。
- 发条巨龙启动后，原命令对三类材料各移除999份；不将剧情中“只用了一半”的说法解释为实际返还物品。最终胜利后解锁原成就，结局给予一只发条巨龙并返回世界地图。六个战斗失败均进入扩展失败页，调用已译通用难度提示。
- 12项战斗任务逐条核对：酒馆战第5回合结束前获胜得两根银锭，无阵亡获胜得獠牙钉锤；守卫战第8回合结束前消灭钢铁魔像得暗夜护符，阵亡不超过2个并获胜得两份迅捷灵药；纯铁战消灭烈焰多头蛇得混沌护符，第6回合结束前消灭所有元素生物得红宝石；煤矿战第5回合结束前消灭腐化蜘蛛得两份高效解毒剂，获胜得两根金锭；龙骨战击败龙巫妖得猎魔人护符，获胜得抗魔戒指；最终战击倒发条巨龙得两份元素防护药剂，无阵亡获胜得金锭与红宝石。
