## 宁静林地

地点使用宁静林地 (Tranquil Grove)，叙述中的 Dream Forest 暂译梦境森林 (Dream Forest)。Seedling 是材料“幼苗”，Saproling 是单位“幼树人”，避免混淆。

| 培育单位 | 消耗幼苗 |
| --- | ---: |
| 幼树人 | 5 |
| 曼德拉草根 | 3 |
| 菌人 | 2 |
| 沼泽藤蔓 | 2 |

四种服务均先扣除相应幼苗，再给予一名对应单位，播放结果对话并返回当前页面。已核对全部四档授予命令：进度低于0.4使用 `give-unit`，0.4至低于0.7使用 `give-regular`，0.7至低于0.9使用 `give-veteran`，0.9起使用 `give-elite`。说明沿用原文“单位的经验取决于游戏进度”，不承诺固定经验值或每日限额。

幼树人分支还根据混沌战役条件登记树人／腐化树人的已知类型，菌人与沼泽藤蔓分支也登记进阶类型；这些不是额外赠送单位。保留 `${item-SeedlingItem-count}`、四处 `=BR=` 及调试选项标签，不启用调试功能。

## 灵魂之井

地图名称使用灵魂之井 (Well of Souls)；原文说明写作 Souls Well 时保留该英文形式。亡灵之王与爱德华爵士沿用现有译名。献祭叙事保留原作的黑暗氛围，不扩大暴力细节。

| 选择类别 | 奖励物品 |
| --- | --- |
| 地精 | 黑暗匕首 |
| 矮人 | 死亡战士护甲 |
| 骑士 | 幻影之盾 |
| 巨魔 | 死亡战士头盔 |
| 鹰身女妖 | 全视之眼 |
| 兽人 | 燃烧战斧 |
| 菌人 | 荆棘手镯 |
| 祭司 | 地狱之盾 |
| 死灵法师 | 骨烛 |

九个菜单分别使用种族分组选择单位，并调用对应 `on-function-2` 至 `on-function-10`。移除单位、设置已使用状态、播放对话和发放物品都受非空选择条件保护；取消选择后只返回页面。移除命令为 `remove-units-but-heroes`，未将其改成可献祭英雄的承诺。九个独立状态分别限制各类献祭一次，译文明确写作“此类献祭仅限一次”，并保留九处 `=BR=`。

物品译名按实际奖励统一，包括原文旧称 Death Warrior Armor／Helmet 对应的“死亡战士护甲／头盔”，以及 `FlameAxeItem` 对应的“燃烧战斧”。Priests 使用种族标签“祭司”，不因调试命令添加僧侣就把整个类别译成僧侣。

新增独立战役对话依赖 `DXX_SoulsWell_sacrifice`、`FXX_SoulsWell_sacrifice`，留给战役协作者处理；外部战役对话引用累计28组。矮人献祭的有效脚本先无条件于战役播放通用对话，再依据战役播放通用或矮人专属对话，因此非矮人战役存在两次通用对话播放命令。此为现有脚本问题，本批仅记录，未修改逻辑或删改译文掩盖。
