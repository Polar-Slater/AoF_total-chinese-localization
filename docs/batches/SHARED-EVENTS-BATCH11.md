## 译法与流程

沿用恶魔之心、恶魔契约、凶魔与秘会等术语。Mephistopheles 暂译梅菲斯托费勒。地图标签及具名地点提示采用“恶魔城 (Demon City)”。“冥界秘会”是组织名称，与地点“冥界 (Underworld)”区别处理。

契约使者将奴隶改口称为自愿效劳的部下，又轻描淡写地带过死后的灵魂代价；保留这种诱导性的说话方式，同时让选择说明明确表达实际代价。原文 `lose -1 base HP` 按扣减含义译为“基础生命值永久减少1点”，不把双重负号理解成增加，也不误写为一次性受到伤害。此数值来自原文提示，签约脚本实际施加 `DemonPact` 属性。

依据 `shared-demoncity.xml` 核对：

- 暂缓：仅执行 `noop-final`，不设置拒绝标记。
- 签约：向英雄施加 `DemonPact`，关闭原商店 `LevelDemonCity02`，开放可招募恶魔的 `LevelDemonCity03`。
- 拒绝：将 `demon-city-available` 设为 `no`，阻止后续契约邀约；不将其误译为关闭整个恶魔城。
- 原始邀请受已开放恶魔城、阵营／战役、时间等条件约束，未更改触发条件或作出“任何战役都能签约”的承诺。

混沌剧情战役入城时调用 `CXX_DemonCity_enter`，这是独立战役资源。本批记录该依赖并留待战役协作者处理，未将其计入已译通用对话。通用XML验证目前共记录23组外部战役对话引用。
