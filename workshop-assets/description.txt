[h1]Age of Fear: Total — 简体中文汉化 / Simplified Chinese Translation[/h1]
[b]开发中 · 部分汉化 / Work in progress · Partial translation[/b]
本模组旨在逐步汉化游戏界面、玩法说明、共享事件及全部战役。目前已完成第一阶段界面翻译，非完整汉化。
This mod aims to translate the interface, gameplay descriptions, shared events and all campaigns into Simplified Chinese. The first interface batch is complete; this is not yet a complete localization.
本模组开发依赖大量AI翻译，并由人工校对。
This mod development extensively depends on AI and proofread by human.

[h2]使用方法 / How to use[/h2]
[olist]
[*]订阅本创意工坊模组并重新启动游戏。 / Subscribe this Workshop mod and restart the game.
[*]打开 Options → Screen → Language。 / Open Options → Screen → Language.
[*]选择 [b]Chinese (Simplified) - Test[/b]。
[/olist]
语言选项保留英文名称，以避免切换语言前显示方框。未翻译内容会显示英文。
The language option deliberately uses an English name to avoid missing-glyph boxes before switching languages. Untranslated content falls back to English.
